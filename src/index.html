三個步驟，不用教就會

第一次用的朋友，點開連結就知道怎麼記。

  1. 開一個群組

    填群組名稱和成員，選結算用的幣別。不用帳號，也不用 Email。

  2. 記帳，傳連結

    誰付了多少、哪些人要分，記完按「分享連結」貼到群組。朋友記完再把連結傳回來，會自動合併。

  3. 一鍵結清

    自動算出最少轉帳，產生附收款帳號的結算圖片。還完錢按「已還款」，這筆就清了。

常見問題

真的完全免費嗎？

是的。沒有付費版、沒有廣告，也沒有筆數限制。SplitLink 是 WeeklyShip AI 的開源作品，程式碼以 MIT 授權公開在 GitHub。

朋友需要下載 App 或註冊嗎？

不需要。朋友點開連結就能看帳、記帳，手機或電腦的瀏覽器都可以。想要像 App 一樣使用，可以「加到主畫面」，之後沒網路也能打開。

大家同時記帳，資料會不會打架？

不會。每筆帳都有自己的編號和修改時間。打開別人傳來的連結時，SplitLink 會逐筆比對，新增的補上、修改過的以最後修改為準、刪除的同步刪除，不會整本被覆蓋。

換手機或清除瀏覽資料，帳會不見嗎？

帳本存在瀏覽器裡。清除瀏覽資料前，只要把最新的分享連結留在群組裡，或在「設定」匯出 JSON 備份，隨時都能再匯入回來。

匯率怎麼算？

每個群組有一個「主幣別」。記其他幣別時，用你輸入的匯率換算；也可以在設定裡按「抓取最新匯率」，從公開匯率服務取得參考匯率。所有金額都換算成最小單位的整數計算，總和一定對得上。

連結會不會太長，LINE 傳不出去？

帳本會先轉成精簡格式再壓縮。100 筆帳大約 2,700 字元，遠低於 LINE 單則訊息 5,000 字的上限。真的很大本的帳，也可以改傳 JSON 備份檔。

SplitLink 會幫我們轉帳或收款嗎？

不會。SplitLink 只負責記帳和計算，不經手任何金錢。實際轉帳請用你們習慣的銀行或支付工具。
