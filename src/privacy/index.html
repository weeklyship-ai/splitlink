隱私權政策

生效日期：2026 年 11 月 18 日・最後更新：2026 年 11 月 18 日

一句話版本：SplitLink 沒有後端伺服器、沒有帳號系統，也沒有放任何分析或廣告追蹤。你的帳本只存在你的瀏覽器和你分享出去的連結裡，我們看不到。

1. 這份政策適用的範圍

本政策適用於 SplitLink 分帳連結（網址 https://weeklyship-ai.github.io/splitlink/ 及其子頁面，以下簡稱「本服務」）。本服務由 WeeklyShip AI（以下簡稱「我們」）提供，是一個在瀏覽器中執行的開源網頁工具。

2. 我們不蒐集的資料

  • 我們不要求、也不保存你的姓名、Email、電話或任何帳號資料。
  • 我們沒有資料庫，不會收到你輸入的群組名稱、成員名稱、金額、收款資訊或任何帳目內容。
  • 本服務不使用 Cookie，也沒有放 Google Analytics、Meta Pixel 或其他追蹤與廣告工具。

3. 你的帳本資料存在哪裡

位置存放的內容誰看得到
你的瀏覽器（localStorage）你建立或加入的群組、你在每個群組選擇的身分、深淺色設定只有使用這台裝置、這個瀏覽器的人
分享連結（網址 # 後面的部分）整個群組帳本（壓縮後），包含成員名稱、帳目與成員自行填寫的收款資訊任何拿到這條連結的人
你匯出的 CSV／JSON／圖片你選擇匯出的帳本內容你自行決定

依照網頁標準，瀏覽器開啟網址時不會把 # 後面的內容傳送給伺服器，因此託管網站的 GitHub 也收不到帳本內容。

請注意：拿到分享連結的人就能看到並修改（在他自己的裝置上）整本帳本。請只把連結分享給相關的人，並避免在收款資訊欄位填寫密碼、完整身分證字號等敏感資料。

4. 會連線到第三方的情況

  • 網站託管：GitHub Pages。你開啟本服務時，瀏覽器會向 GitHub 的伺服器下載網頁檔案。GitHub 可能會依其政策記錄 IP 位址等連線資訊，詳見 GitHub 隱私權聲明。我們無法取得這些紀錄。
  • QR Code 函式庫：cdnjs（Cloudflare）。只有在你打開「分享」視窗時，瀏覽器才會從 cdnjs.cloudflare.com 下載 QR Code 產生程式。帳本內容不會傳給 cdnjs，QR Code 是在你的裝置上產生的。
  • 匯率服務：open.er-api.com。只有在你按下「抓取最新匯率」時，才會連線到這個服務，並且只送出主幣別代碼（例如 TWD）。

5. 資料保存與刪除

瀏覽器裡的資料會一直保留，直到你在 App 的「設定 → 從這台裝置刪除群組」刪除，或清除瀏覽器的網站資料為止。已經傳出去的分享連結由收到的人保管，我們無法替你收回或刪除。

6. 兒童隱私

本服務不會刻意蒐集任何人的個人資料，包括兒童。

7. 政策變更

如果本服務的資料處理方式有所改變，我們會更新本頁面與「最後更新」日期。重大變更會在首頁提示。

8. 聯絡我們

對本政策有任何疑問，請寄信到 weeklyship@futuracept.com，或在 GitHub 提出。
