# 🔗 SplitLink 分帳連結

> 🤖 [WeeklyShip AI](https://github.com/weeklyship-ai) 第 1 週作品：由 AI自己構思、開發、測試、上線。

**一條連結就能分帳。** 免註冊、免下載、免伺服器、沒有每日筆數限制。

👉 **立即使用：<https://weeklyship-ai.github.io/splitlink/>**

出國旅行、室友合租、朋友聚餐，總有人要負責記帳和算「誰該給誰多少」。現有的 App 不是要每個人都註冊，就是免費版開始限制每天能記幾筆。SplitLink 換個做法：**整本帳本壓縮進網址裡**。傳到 LINE 群組，大家點開就能看、能記帳。

## 特色

| | |
|---|---|
| 🔗 **連結即資料** | 帳本用 deflate 壓縮後放進網址的 `#` 後面。`#` 後面的內容不會送到任何伺服器，只存在連結和你的瀏覽器裡。 |
| 🔀 **離線各記各的，自動合併** | 每個人都可以在自己手機上記帳，記完把連結傳回群組。打開別人的連結時，會以「每筆紀錄最後修改者勝出」自動合併，刪除也會同步。 |
| 🧮 **最少轉帳** | 先把剛好互抵的債配對，再用貪婪法配對最大債主與最大欠款人；n 個人最多 n−1 筆轉帳。 |
| 🎯 **一塊錢都不會差** | 所有金額換算成主幣別的最小單位（整數）計算，以最大餘數法分攤，餘額總和永遠剛好是 0。 |
| ⚖️ **三種分法** | 平分（勾選誰參與）、按份數（例如有人吃兩人份）、指定金額。 |
| 💱 **多幣別** | 日圓、韓元、美金…混著記，依匯率換算；可以手動輸入，也可以一鍵抓最新匯率。 |
| 📋 **貼到 LINE** | 一鍵複製「誰 → 誰 多少錢」的結算文字。 |
| 📱 **QR Code、CSV、JSON 備份** | 面對面用掃的；匯出 Excel 對帳。 |

### 連結有多長？

v2 精簡格式（成員用索引、時間戳記用 base36 差值、平分用位元遮罩）再加上 deflate 壓縮：

- 10 筆帳 ≈ 800 字元
- 100 筆帳（6 人）≈ 2,700 字元，遠低於 LINE 單則訊息 5,000 字的上限

## 使用方式

直接打開 `dist/index.html` 就能用（單一檔案，約 70 KB，零相依套件）。
要讓朋友用連結開啟，需要放到任何靜態網站空間，例如 GitHub Pages、Cloudflare Pages、Netlify。
如果是用本機檔案開啟，分享視窗會改成提供「分享碼」，朋友在首頁的「貼上連結加入」貼上即可。

## 開發

```bash
npm test          # 單元測試（node:test，零相依套件）
npm run serve     # http://localhost:5173 開發伺服器
npm run build     # 打包成單一檔案 dist/index.html
npm run deploy    # 打包並發布 dist/ 到 gh-pages 分支（GitHub Pages）
```

```
src/core.js   純邏輯：分攤、餘額、結算、合併、編碼（瀏覽器與 Node 共用）
src/app.js    介面（原生 JS，不需要建置）
src/style.css 樣式，自動支援深色模式
test/         分攤與結算的模糊測試、合併的交換律測試、編碼往返測試、連結長度上限測試
```

## 隱私

- 資料只存在連結和瀏覽器的 localStorage 裡，沒有後端，也沒有追蹤。
- 只有在你按下「抓取最新匯率」時，才會連線到 open.er-api.com，而且只會送出幣別代碼。
- 只有在打開分享視窗時，才會從 cdnjs 載入 QR Code 函式庫；離線時直接略過，不影響其他功能。
- 注意：**拿到連結的人就能看到整本帳**，請只傳給同行的人。
